# EglantinePS5 – Custom Builds

Unofficial custom builds of **EglantinePS5**, compiled from source for PlayStation 5.

This repository provides independently compiled releases of EglantinePS5, making them easier to download and install.

All credit for the original project and its development goes to **[@heydemoura](https://github.com/heydemoura)**.

## About EglantinePS5

EglantinePS5 is a PlayStation 5 homebrew project that brings emulation capabilities to the console.

For the original project, source code and development updates, visit:

**[EglantinePS5 – Original Repository](https://github.com/heydemoura/EglantinePS5)**

## Installation

1. Download the latest release ZIP archive.

2. Extract the archive on your computer.

3. Connect to your PS5 using an FTP client.

4. Copy the `PPSA98515` folder to:

   `/data/homebrew/PPSA98515`

5. Launch EglantinePS5 through your preferred homebrew launcher, such as ShadowMountPlus.

**Important:** Do not delete `/data/eglantineps5` when updating or installing the application. This directory contains application data and configuration files.

## Requirements

* PlayStation 5 with a compatible jailbreak environment.
* etaHEN.
* ShadowMountPlus 1.7beta4 or newer.
* A local ELF loader listening on TCP port 9021.

Additional configuration may be required depending on your PS5 environment.
